Download troubleshooting tips
  • Use cookies when you see bot checks or private/member-only restrictions.
  • For single videos from playlist pages, paste the Share link instead of the playlist URL.
  • Enable playlist checkbox only when you actually want all playlist items.
  • If downloads hang, update yt-dlp (nightly can help) and retry with cookies.
  • If high quality arrives as separate streams, yt-dlp + ffmpeg will merge automatically.
  • For deep debugging, run yt-dlp with -v in terminal using the same URL/cookies.
